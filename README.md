# App Portal

A single Cloudflare Worker that hosts a registry of small prototype apps — add a file, register it, and ship.

See **[PLAN.md](./PLAN.md)** for architecture, how to add apps, and run/deploy instructions.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:8787](http://localhost:8787). The first app is the [MAF 180 Calculator](/apps/maffetone).
